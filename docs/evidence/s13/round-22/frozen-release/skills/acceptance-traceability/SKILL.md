# Acceptance Traceability

For every requirement/criterion, locate:
1. implementation evidence,
2. test/validator evidence,
3. runtime or contract evidence when applicable.

Classify each criterion as COVERED, PARTIALLY_COVERED, NOT_VALIDATED or NOT_COVERED. Cite files/commands rather than relying on summaries. A passing unrelated test does not satisfy traceability. Never rewrite the criterion from implementation behavior.
